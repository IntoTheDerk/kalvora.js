# Wallet Creation

This module handles wallet creation and key management for the Kalvora network with comprehensive HD wallet support, multiple key types, and advanced features.

## What it does

- Creates HD wallets using BIP39 mnemonics
- Supports Ed25519 and Ed448 key types
- Generates addresses with multiple hash algorithms
- Follows SLIP-0010 standard for EdDSA curves

## Key Features

- **HD Wallets**: Create multiple addresses from one mnemonic
- **Multiple Key Types**: Ed25519 (fast) and Ed448 (maximum security)
- **Hash Chaining**: SHA3-256, SHA3-512, BLAKE3
- **SLIP-0010 Compliance**: Fully hardened derivation paths for EdDSA security
- **Extended Keys**: Full xpriv/xpub support for advanced use cases

## Supported Key Types

- **Ed25519**: Fast, efficient, widely supported
- **Ed448**: Maximum security, larger keys, higher computational cost

## Supported Hash Algorithms

- **BLAKE3**: Modern, fast, secure - typical for most wallets
- **SHA3-256**: Time tested security
- **SHA3-512**: Higher security, larger output

## Hash Chaining

Hash chaining applies multiple hash functions sequentially. For example, `[SHA3_256, BLAKE3]` means: `BLAKE3(SHA3_256(publicKey))`. This creates unique address spaces and additional security layers.

## Basic Usage

```typescript
import { WalletFactory, KEY_TYPE, HASH_TYPE } from "<hosted location>";

const factory = new WalletFactory();

// Create a basic wallet
const wallet = await factory.createWallet({
  keyType: KEY_TYPE.ED25519,
  hashTypes: [HASH_TYPE.SHA3_256],
  mnemonic: "your twelve word mnemonic phrase here...",
});

console.log("Address:", wallet.address);
console.log("Private Key:", wallet.privateKey);
console.log("Public Key:", wallet.publicKey);
```

## Advanced Usage

### Different Key Types

```typescript
// Ed25519 wallet (recommended for most use cases)
const ed25519Wallet = await factory.createWallet({
  keyType: KEY_TYPE.ED25519,
  hashTypes: [HASH_TYPE.SHA3_256],
  mnemonic: "your mnemonic phrase here",
});

// Ed448 wallet (maximum security)
const ed448Wallet = await factory.createWallet({
  keyType: KEY_TYPE.ED448,
  hashTypes: [HASH_TYPE.SHA3_512],
  mnemonic: "your mnemonic phrase here",
});
```

### Hash Chaining

```typescript
// Single hash
const singleHashWallet = await factory.createWallet({
  keyType: KEY_TYPE.ED25519,
  hashTypes: [HASH_TYPE.SHA3_256],
  mnemonic: "your mnemonic phrase here",
});

// Hash chaining (applied right-to-left)
const chainedWallet = await factory.createWallet({
  keyType: KEY_TYPE.ED25519,
  hashTypes: [HASH_TYPE.SHA3_512, HASH_TYPE.BLAKE3],
  mnemonic: "your mnemonic phrase here",
});
```

### HD Wallet Derivation

```typescript
import { deriveMultipleWallets } from "<hosted location>";

// Derive multiple wallets from the same mnemonic
// For account-based systems like Kalvora, accountIndex is incremented for each wallet
const wallets = await deriveMultipleWallets({
  mnemonic: "your mnemonic phrase here",
  keyType: KEY_TYPE.ED25519,
  hashTypes: [HASH_TYPE.SHA3_256],
  count: 5, // Generate 5 wallets
  hdOptions: {
    accountIndex: 0, // Will auto-increment for each wallet (0, 1, 2, 3, 4)
  },
});

// Each wallet has a unique address from the same seed
// Derivation paths: m/44'/5258'/0'/0'/0', m/44'/5258'/1'/0'/0', etc.
wallets.forEach((wallet, index) => {
  console.log(`Wallet ${index}:`, wallet.address);
});
```

### Importing Existing Mnemonics

```typescript
// Import an existing mnemonic phrase
const importedWallet = await factory.createWallet({
  keyType: KEY_TYPE.ED25519,
  hashTypes: [HASH_TYPE.SHA3_256],
  mnemonic:
    "abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about",
});

// Same mnemonic + same settings = same address
console.log("Address:", importedWallet.address);
```

## Security Considerations

### SLIP-0010 vs BIP44 Incompatibility

**Critical:** This SDK uses **SLIP-0010** fully hardened derivation paths (`m/44'/5258'/0'/0'/0'`) which are **incompatible with BIP44** wallets.

**Why SLIP-0010?**

- EdDSA curves (Ed25519/Ed448) cannot perform public key derivation
- Mixed hardened/normal derivation creates security vulnerabilities
- Full hardening is a cryptographic requirement for EdDSA security

**Impact:** Addresses generated by BIP44 wallets cannot be reproduced by this SDK and vice versa. This is a necessary security trade-off.

### Memory Safety

```typescript
// Automatic secure memory clearing
wallet.secureClear(); // Clears sensitive data from memory

// Manual cleanup for sensitive operations
try {
  const sensitiveData = await performOperation();
  // ... use data
} finally {
  // Ensure cleanup

```

**Audited Libraries Only:**

- **[@noble/curves](https://github.com/paulmillr/noble-curves)** - Industry-standard Ed25519/Ed448
- **[@noble/hashes](https://github.com/paulmillr/noble-hashes)** - Secure hash functions
- **[bip39](https://github.com/bitcoinjs/bip39)** - BIP39 mnemonic generation
